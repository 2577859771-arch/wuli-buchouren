## 启动完整网站

需要 Node.js 22.13+（使用内置 SQLite）；不需要额外数据库安装。

```sh
npm ci
npm run build
npm test
npm start
```

打开 `http://localhost:4178/`，**不要双击 index.html**。无模型配置时，课程/实验可用，文字题使用明确标注的规则解析；照片不会被假装识别。部署到公网时配置环境变量、HTTPS 和持久磁盘，数据库默认在 data/physics.sqlite。可用 `node --env-file=.env scripts/serve.mjs` 加载自行配置的 .env；不要把 .env 发给第三方。

完整服务端构建在 `dist/server/index.js`；也可适配 Worker/D1，但数据库迁移必须先完成。压缩包不带 node_modules、.env、数据库、用户数据或浏览器会话。

## 接口

| 路径 | 方法 | 用途 |
| --- | --- | --- |
| /api/session | GET | 用户、识图/配图/邮件服务的真实配置状态 |
| /api/register、/api/login、/api/logout | POST | 邮箱账号和安全 Cookie |
| /api/ask | POST | question/image/topic/level/history；识别、解答和过程参数 |
| /api/illustration | POST | 可选 AI 辅助场景图；已有精确示意图无需此服务 |
| /api/forgot-password、/api/reset-password | POST | 发找回邮件 / 用单次令牌改密码 |
| /api/send-verification、/api/verify-email | POST | 发验证邮件 / 验证单次令牌 |
| /api/feedback | POST | 账号用户主动提交纠错反馈 |

所有 POST 都验证同源 Origin。密钥仅在服务端读取。图片和问答只保留在页面内存，不写入用户数据库；反馈中的题目上下文由用户主动提交才保存。
